# Gesture guides

Short looping animations that each teach one SciQLop manipulation, drawn as a simplified window.

| File | Shows |
| --- | --- |
| `new-panel-and-time-range.svg` | Add a plot panel with the + button, then type its start date and duration. |
| `plot-a-product.svg` | Open the Products pane, drag a product onto a panel. |
| `drop-on-a-panel.svg` | Where to drop on a panel that has plots: on a plot, on its top edge, on its bottom edge. |
| `show-a-catalog.svg` | Open the Catalogs pane, drag a catalog onto a panel: its events show as spans. |
| `create-an-event.svg` | Catalog mode Edit, then Shift+click, move, click again. |
| `jump-to-an-event.svg` | Catalog mode Jump: pick an event in the list, the panel goes to it. |
| `edit-an-event.svg` | In Edit mode: drag an edge to resize, the middle to move, right-click to delete. |

Each file is a standalone SVG animated with CSS: no script, no image. It follows the light or dark
theme of whatever displays it, and shows a still picture where animation is off. It plays in a web
page and in a README, and inside SciQLop through Qt's own SVG renderer (Qt 6.10 or later), which takes
the colours of the current theme.

The files are generated by `SciQLop/components/guides/authoring/core/*.py`:

    uv run python -m SciQLop.components.guides.authoring.core.plot_a_product SciQLop/components/guides/resources

Inside SciQLop they are listed in Help › Guides and in the command palette ("Guide: …"). A plugin adds
its own with `register_guide`; the `sciqlop-gesture-guides` agent skill explains how to draw one.
